A deterministic Node program that writes the one line the office printer finally says back to everyone staring at it: it has fed this office 41,209 sheets and jammed on exactly one — the report due in five minutes. It counted. It was not an accident. Weary, literal and faintly passive-aggressive, the flat logic of a device that has counted every sheet it ever fed.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (set `ENTRY_OUTPUT` to point it at a scratch path for a local run instead). Node 22.18 or later, no dependencies, no network, no randomness — every run writes the same 135 characters.
